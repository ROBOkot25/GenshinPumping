# GenshinPumping
Программа, которая читает скриншоты характеристик персонажей в Genshin Impact, преобразовывает, ищет их в таблице Excel и записывает данные

## Возможности
- Распознавание текста со скриншотов (Tesseract OCR)
- Определение типа скриншота: персонаж, оружие, артефакты, таланты
- Извлечение характеристик: HP, ATK, DEF, мастерство стихий, криты, восстановление энергии
- Запись в Excel-шаблон (ClosedXML)
- Цветовая адаптация OCR под элемент персонажа

## Технологии
- C# (.NET Framework / .NET Core)
- Tesseract
- ClosedXML
- System.Drawing

## Как запустить
1. Открой bin\Debug - там лежит сама программа и основные папки
2. Положи скриншоты в папку `screenshots` (там уже есть несколько скриншотов для примера)
3. Запусти `GenshinPumping.exe`
4. Результат будет выведен в консоле

## Статус
Рабочий прототип. Имеет определённые проблемы с чтением определённых надписей (особенно с низкой контрастностью) и часто бывает неточен. Использую для личных нужд.
